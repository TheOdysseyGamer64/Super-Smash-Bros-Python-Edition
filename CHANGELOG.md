# Changelog

Notable changes to **Super Smash Bros. Python Edition** are recorded here.

## [Unreleased] — v1.5.0 development

### Added
- Fighter-specific resource mechanics for Mario, Luigi, Sora, Mii Swordfighter, Duck Hunt Duo, Ness, Kirby, Kazuya, and R.O.B.
- Automated tests for fighter data, resource helpers, resource caps, and selected resource-powered attacks.
- Documentation for running the game and its automated tests locally.

### Changed
- Improved Kazuya's Rage gain calculation so missing HP is converted to Rage using the intended five-HP increments.
- Updated the README to reflect the current development features and distinguish development work from the latest published release.
- Removed duplicate resource helper definitions and an unused import identified by lint checks.

### Notes
- v1.5.0 is still in development and has not been marked as a published release here.
- Resource values and combat balance may change before release.
